Introduction

REST API v1 for FacilityDesk: work orders, technicians' jobs, sites, assets and dashboards.

Base URL: http://facilitydesk.test 
All endpoints live on the central domain under `/api/v1`. Your workspace is taken from your token, never from the URL or body,
so a record from another workspace is always a `404`.

- **Auth:** `POST /auth/login` with your workspace slug, email, password and a device name returns a bearer token (30 days).
- **Errors:** `{ "message": "...", "errors": { "field": ["..."] } }`. `401` no/invalid token, `403` not allowed, `404` not found, `422` validation or an illegal status change, `429` rate limited.
- **Limits:** 60 requests a minute per token; 5 login attempts a minute per IP.
- **Times** are ISO 8601 in UTC; show them in the work order's `site.timezone`.

Authenticating requests

To authenticate requests, include an Authorization header with the value "Bearer {YOUR_TOKEN}".

All authenticated endpoints are marked with a requires authentication badge in the documentation below.

Get a token from POST /api/v1/auth/login.

Authentication

Tokens are per device. Send them as Authorization: Bearer <token>.

Log in

Exchanges workspace, email and password for a bearer token. Limited to 5 attempts a minute per IP. Wrong workspace, email or password all give the same answer, so the endpoint cannot be used to discover accounts.

Example request:
curl --request POST \
    "http://facilitydesk.test/api/v1/auth/login" \
    --header "Content-Type: application/json" \
    --header "Accept: application/json" \
    --data "{
    \"tenant\": \"acme\",
    \"email\": \"tech@acme.test\",
    \"password\": \"password\",
    \"device_name\": \"Pixel 8\"
}"

const url = new URL(
    "http://facilitydesk.test/api/v1/auth/login"
);

const headers = {
    "Content-Type": "application/json",
    "Accept": "application/json",
};

let body = {
    "tenant": "acme",
    "email": "tech@acme.test",
    "password": "password",
    "device_name": "Pixel 8"
};

fetch(url, {
    method: "POST",
    headers,
    body: JSON.stringify(body),
}).then(response => response.json());

Raise a work order

requires authentication

Send as multipart/form-data to attach photos.

Example request:
curl --request POST \
    "http://facilitydesk.test/api/v1/work-orders" \
    --header "Authorization: Bearer {YOUR_TOKEN}" \
    --header "Content-Type: multipart/form-data" \
    --header "Accept: application/json" \
    --form "photos[]=@/private/var/folders/12/9yccm58d3lq_zkrth3lv7cvc0000gn/T/phpdJfnwg" 
const url = new URL(
    "http://facilitydesk.test/api/v1/work-orders"
);

const headers = {
    "Authorization": "Bearer {YOUR_TOKEN}",
    "Content-Type": "multipart/form-data",
    "Accept": "application/json",
};

const body = new FormData();
body.append('photos[]', document.querySelector('input[name="photos[]"]').files[0]);

    method: "POST",
    headers,
